# MedicusMinds NEET

NEET preparation syllabus tracker, smart auto-backlog manager, revision & habit engine.

- **Live App:** https://rishabh1502verma-techmedicus.github.io/medicusminds-neet/
- **Channel:** [@medicusminds_official](https://www.youtube.com/@medicusminds_official)

## Key Features
- Physics (25), Chemistry (25), and Biology (1–32) chapter tracking
- Exam Countdown and Smart Auto-Backlog
- Habit & Streak Maker and Mock Test Log
- Local browser storage with JSON Backup & Restore
